# Assets Directory for Aman's Portfolio

Drop your actual assets in this folder:

1. **`aman-photo.jpg`** (or `.png` / `.webp`):
   - Your personal photograph for the **About** section.
   - Recommended aspect ratio: 4:5 or 1:1, high resolution.

2. **`signature.png`** (or `.svg`):
   - Optional digital signature image if you wish to use a vector/transparent signature file instead of the built-in cursive font.

3. **`logo.svg`** (or `.png`):
   - Optional custom logo or monogram if needed.

All paths can be easily modified in `src/data/portfolioData.js`.
